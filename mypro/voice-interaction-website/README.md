# Voice Interaction Website

This project is a simple website designed to convey information to rural areas using voice interactions.

## How to Run

1. Install dependencies:
    ```bash
    npm install
    ```

2. Start the development server:
    ```bash
    npm start
    ```

3. Open your browser and navigate to `http://localhost:8080`.

## Project Structure

- `src/`
  - `css/`
    - [styles.css](http://_vscodecontentref_/1): Styles for the website.
  - `js/`
    - `scripts.js`: JavaScript for handling voice interactions.
  - `assets/`
    - `audio/`
      - `sample-audio.mp3`: Sample audio file.
  - `voice.html`: Main HTML file for the website.
